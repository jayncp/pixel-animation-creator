# 像素角色动画：可复用 Skill

这是可携带的技能文件包，不会自动安装到个人账号，也不包含付费软件或第三方教程素材。

## 在新对话继续

把本包与角色项目包一起上传。无需复述之前的逐步指导，可以直接说：

“请读取 pixel-character-animation/SKILL.md，并根据另一个包的 project_resume.json 继续这个角色。制作【你想要的动作】，自主检查身份、动作节奏、边缘和实际播放效果，输出可编辑文件及最终动画。”

目录名变化不影响方法。让助手以项目里的最终文件索引为准，不要仅凭版本号挑旧文件。原生软件是否可用、是否需要安装或授权，须在新环境重新确认；旧项目记录不提供永久授权。

## 换一个角色

上传新角色参考图，可以说：

“使用这个 Skill，为新参考角色制作【待机/施法/转身等动作】。不要沿用旧角色素材或身体结构，先建立新母版和身份约束，再自主制作、检查并迭代。”

技能复用的是制作和评审方法，不是把旧角色的三尾、衣服、分辨率或帧数套给所有角色。256 像素只是细节较多时可考虑的工作尺寸，不是最低要求。

## 包里有什么

- SKILL.md：主流程与关键验收要求。
- references/：续作/新角色、动作设计、边缘与时间连续性、工具交付、CLI 使用及研究依据。
- scripts/pixel_anim.py：可移植检查、时序分析、接触表、GIF/图集导出和边缘改动诊断。
- assets/action_manifest.example.json：按实际项目填写的参数示例，不是固定动作配方。
- tests/ 与 TEST_RESULTS.md：已执行的辅助工具测试及其边界。

辅助脚本不会自动画好新角色，也不能靠数值证明动作自然。高质量结果仍需要具备图像理解的助手观察真实帧、实际速度播放、发现问题并修改。若播放或原生编辑能力不可用，应明确说明未完成的验收，而不是宣称一次生成完美。
