# 使用说明

这是全流程像素角色动画技能。先让执行 agent 阅读 `SKILL.md`，再按当前阶段读取相关参考文档，不需要一次加载全部资料。

## 可以从哪些地方开始

- 只有文字：先使用可用生图能力建立形象，再整理为目标尺寸的像素画。
- 普通参考图：保留辨识特征，重新组织像素块、色板和轮廓，不只缩图。
- 像素参考图：保留原画设计和网格，按要求适配尺寸/角度。
- 已有多角度图：检查一致性后进入动作研究。
- 已有动画草稿：检查节奏、支撑、比例和连续性后补帧与修细节。
- 只修边缘或导出：直接接入相应阶段，不强迫重新设计角色。

新项目未指定尺寸时，参考画布默认为每视角 256×256。旧项目继续时默认保留已有尺寸。完整新参考集未指定角度时先做正面、三分之四、侧面、背面，并标明推断或镜像视角。动画帧数按需要决定。

## 两类文件不要混淆

本 skill 保存通用方法与工具。角色项目保存原图、实际身份特征、多视角、时间轴、图层、动作和最终索引。重新开对话时，可以同时上传 skill 仓库 ZIP 与角色项目 ZIP，让 agent 读取各自的开始说明。原项目若有外层解包脚本，要先查看再按说明在新目录解包。

## 工具与权限

优先使用执行环境实际提供的生图工具。发现 Codex CLI 仅表示一个候选路径，不能保证生图、免费额度或当前登录权限。用户指定模型/服务时按其真实能力调用；付费、登录、第三方上传私有图、许可和安装等仍须遵守实际授权。项目内配置优先，不修改全局设置。

Python 工具负责规格/路径检查、帧/颜色/透明度和封闭透明孔审计、轨迹诊断、逐帧联系表、GIF 和图集导出。它们不自动决定关键姿势、不自动修所有脏像素，也不能判定自然度。实际逐帧看图与 1× 播放不能省略，候选交付前还要请独立复审者看实际图片；没有播放器或复审者就明确标记待验收。

## 可以直接这样提出任务

“使用这个 skill，把以下描述做成 256×256 像素角色多角度参考，暂时不做动画。”

“使用这个 skill 和已有项目，为角色设计快速后退后释放法术的动作，自己调查素材、分析节奏、制作并逐帧修复。”

“使用这个 skill，只修第 18 帧附近尾巴连接处的脏像素，不改时间轴和人物设计。”

交付要求与限制会保留在项目记录中；无需逐步告诉 agent 应该检查眼睛、鞋袜或尾巴。技能尚不保证完全没有人工反馈，也没有对所有人物风格/运行环境做过全面验证。
